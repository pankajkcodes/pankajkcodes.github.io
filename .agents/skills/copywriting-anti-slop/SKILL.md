# Copywriting & Anti-Slop Skill

This skill governs all text, headlines, case studies, bios, and service descriptions across the portfolio. It eliminates generic AI writing habits and replaces them with direct, punchy, human voice.

---

## 1. Banned AI Words & Phrases ("The Slop Dictionary")

Never use these notorious LLM telltale markers:

| Slop Word / Phrase | Why It’s Banned | What to Use Instead |
| :--- | :--- | :--- |
| **"delve", "dive deep into"** | Overused GPT filler | "explore", "built", "analyzed", or explain directly |
| **"testament to", "a beacon of"** | Melodramatic and artificial | State the concrete result or accomplishment |
| **"tapestry", "symphony", "dance"** | Hallmark AI metaphor | Use concrete, literal descriptions |
| **"In today's fast-paced world..."** | Empty throat-clearing | Cut completely and start directly with the point |
| **"game-changer", "revolutionary"** | Unsubstantiated hype | Show specific metrics, impact, or outcomes |
| **"seamless", "effortlessly"** | Lazy marketing fluff | Describe how it actually works or simplifies things |
| **"furthermore", "moreover", "in summary"** | Stiff essay transitions | Conversational flow, bullets, or direct statements |

## 2. Structural Clichés to Eliminate

### ❌ The Binary Contrast
- *Slop:* "It's not just a website. It's a digital experience that transforms..."
- *Fix:* State what it is clearly: "A fast, responsive web platform built for high conversion."

### ❌ The Fake-Deep / Philosophical Ending
- *Slop:* "Because in the end, code isn't just syntax—it's the canvas where tomorrow is shaped."
- *Fix:* End with a clear call-to-action or summary of results: "Check out the live project on GitHub."

### ❌ Throat-Clearing Openers
- *Slop:* "When it comes to building modern web applications, one thing is certain..."
- *Fix:* Start directly with the action: "I build responsive, high-performance web applications using..."

### ❌ Colon Reveals & Buzzword Stacking
- *Slop:* "The result: an intuitive, cutting-edge, scalable paradigm shift."
- *Fix:* "The redesign cut bounce rate by 34% and improved mobile load times to under 1s."

## 3. Principles for Pankaj's Portfolio Copy

1. **Be Specific & Concrete:**
   - Mention real tools, real problem constraints, and tangible outcomes.
   - Example: Instead of "Built a robust e-commerce engine," write "Engineered a Stripe checkout flow handling 500+ daily orders with zero dropped transactions."
2. **First-Person & Conversational:**
   - Write like a skilled engineer talking directly to a peer or client, not like a corporate PR press release.
   - Use active voice: "I designed and deployed..." rather than "The deployment was orchestrated by..."
3. **Ruthless Editing:**
   - Every sentence must earn its place. If a paragraph can be said in one sentence, reduce it.
   - Cut adjective stuffing ("passionate, results-driven, highly-motivated full-stack developer"). Let the work demonstrate capability.

## 4. Copy Review Checklist

Before finalizing any text on the portfolio, verify:
- [ ] Are any banned words ("delve", "testament", "tapestry", "seamless") present?
- [ ] Does the first sentence get straight to the point without warmup fluff?
- [ ] Are claims backed by concrete tools, metrics, or technologies?
- [ ] Does it sound like an authentic human engineer wrote it?
